# Recording checklist

Use this checklist immediately before recording the 3–4 minute demo.

1. Start `npm run localnet` and wait until the validator reports readiness.
2. Start `npm run dev`, then open `http://127.0.0.1:5179`.
3. Hide terminals, wallets, file manager windows and browser tabs unrelated to BondOps.
4. Start a fresh browser session and click **Launch on-chain demo**.
5. Record the three required flows in this order: voting snapshot, coupon payment, final coupon and redemption.
6. Show the on-chain audit screen at the end: paid DemoUSD total is $22,000.00; outstanding quantity, custody balance and mint supply are zero.
7. Read the narrator script from `DEMO_SCRIPT.md` and host the exported MP4 on YouTube as Unlisted.

Do not show browser storage, the `.local` directory, keypair files, seed phrases or wallet recovery prompts.
